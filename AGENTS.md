# Instruções para o Codex

Ignore completamente:

- node_modules/
- dist/
- build/
- .vercel/
- .firebase/
- coverage/
- .env
- .env.local

Não leia, não edite e não use arquivos dessas pastas como referência.

O código relevante do projeto está principalmente em:

- src/
- public/
- package.json
- tsconfig.json
- vite.config.ts
- eslint.config.js
- index.html

Este é um projeto Vite + React + TypeScript + Firebase.

Respeite:
- TypeScript estrito.
- Use `import type` para tipos.
- Não introduza `any`.
- Não altere regras de negócio sem necessidade.
- Não altere arquivos de configuração sem uma razão clara.
